Playground Admin API reference

Web search that answers an agent's question, not a person's.

One call returns ranked pages with the passages that matter for the agent's objective, inside a character budget you set. Usage is metered per key, so every caller has a monthly limit.

Open the playground API reference

Fast

1 credit

Titles, links and search snippets from the search engine. About a second. Use it to find pages or to answer questions a snippet can settle.

Deep

2 credits

Reads each page and returns the passages that best match the query and objective. Three to four seconds cold, near zero once the pages are cached. Pages that are not ready in time fall back to their snippet and finish loading in the background.

Get started

  1. Create a key

    On the server, once. The key is printed a single time; only a hash is stored.

    lookout create-key --name my-agent

  2. Call the API

    Send the key as a bearer token. Start with fast mode and add an objective when you switch to deep.

    Authorization: Bearer lo_…

  3. Watch usage

    Each key has a monthly credit limit. The admin page shows credits per day, cache share and every key against its limit.
